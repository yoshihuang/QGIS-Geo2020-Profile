about=讀取經濟部地質調查及礦業管理中心 Geo2020「工程地質探勘資料庫」MDB 檔（內建純 Python Access 讀取器，免安裝 ODBC），在地圖上顯示鑽孔位置，並依剖面線、數值地形 (DEM 或等高線) 批次產生地質剖面 QGIS 專案檔 (.qgz)，所有圖層存入 GroProfile.gpkg。剖面包含鑽孔柱狀圖（依 2008 資料作業規範附錄B 工程地質圖元符號，內含全部 131 個圖元）、地形線、土岩界線、地下水位、RQD、SPT、不連續面，以及含圖例、比例尺、格線的版面配置。另提供岩心箱照片檢視工具：點選地層即顯示對應深度的岩心照片。
 Reads Taiwan Geo2020 engineering-geology borehole databases (Access MDB, built-in pure-Python reader, no ODBC needed), shows borehole locations, and batch-generates one geological cross-section project per section line using a DEM or contour layer. Layers (strata columns with the official Geo2020 lithology patterns, terrain, soil/rock interface, groundwater, RQD, SPT, discontinuities) are stored in a single GeoPackage and each project includes a print layout. A core-box photo viewer shows the core photos of a clicked stratum.
