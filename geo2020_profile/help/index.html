操作步驟

步驟 0　準備資料

  • Geo2020 匯出的 MDB 檔（例如 NgeoextNew.MDB）放在一個資料夾中。
  • 岩心箱照片（選用）：放在同一資料夾內，以各鑽孔為子資料夾。Geo2020 標準結構為 <資料夾>\<計畫編號>_Image\<孔號>\<孔號>-<箱號>….jpg； 任何名稱等於孔號的子資料夾（三層以內）也可被辨識。照片深度優先取自 MDB 的 drill_image 資料表， 若無資料則以檔名中的箱號、每箱 7 m 推算。
  • 在 QGIS 中開啟（或新建）一個專案，載入 數值地形（DEM 網格，或含高程欄位的等高線線圖層） 與 剖面線線圖層。剖面線須為投影座標（公尺，例如 TWD97 EPSG:3826），且有一個剖面名稱欄位（如 A、B、C）。 剖面線的畫線方向即剖面由左（A）至右（A'）的方向。

步驟 1　選擇 Geo2020 MDB 資料夾

  • 選擇資料夾後，套件自動找出 MDB 檔並讀取鑽孔資料（不需安裝 Microsoft Access 或 ODBC 驅動程式）。
  • 讀取後，在地圖區加入「Geo2020 鑽孔位置」圖層、標示孔號，並縮放到鑽孔範圍，可檢查鑽孔與剖面線的相對位置。
  • 鑽孔座標系統依 MDB 的 coord_system 自動判定（1 = TWD67 二度分帶、2 = UTM、3 = TWD97 二度分帶），可手動修改。
  • 若資料夾中有各鑽孔的岩心箱照片資料夾，會顯示照片數量；若沒有，會提醒您，產出專案的照片顯示功能將停用。
  • MDB 含多個計畫時，可在「計畫」選單中只選一個計畫。

步驟 2　選擇數值地形

從目前專案的圖層中選擇 DEM（網格）或等高線（線）。選擇等高線時，須指定高程欄位；剖面地形以剖面線與等高線的交點線性內插。 DEM 以雙線性內插取樣，取樣間距 0.25 m。

步驟 3　井口高程來源

  • 數值地形：柱狀圖頂端貼齊地形剖面線（建議，圖面一致）。
  • Geo2020 MDB：採用 MDB 的井口高程。若 MDB 高程與地形相差超過 2 m，執行訊息會提出警告；MDB 無高程的鑽孔改用地形高程。

步驟 4　剖面線與執行範圍

  • 選擇剖面線圖層及名稱欄位。欄位值即輸出的專案檔名（可加前綴、後綴），以及剖面兩端的標示（A 與 A'）。
  • 選「全部剖面」產製圖層中所有剖面；選「只執行選取」則只產製目前選取 (Selected) 的剖面線。

步驟 5　鑽孔與剖面距離

以拉桿設定 5～50 m（預設 10 m）。鑽孔與剖面線的最近距離在此值以內者，投影到剖面線上繪製。

步驟 6　代表位態（選填，建議輸入）

  • 岩層代表位態：輸入層理（或劈理、葉理）的傾向／傾角，例如 120°／35°。程式依每條剖面線的方位計算視傾角 （tan 視傾角 = tan 傾角 × cos(傾向 − 剖面方位)），決定岩層向剖面哪一側傾斜，執行訊息會列出每條剖面的視傾角與傾斜方向。
  • 勾選「改用 MDB 實測傾角」時，各層理／劈理點以 MDB 記錄的傾角計算視傾角，方向仍依代表位態。
  • 斷層代表位態：MDB 有斷層、斷層帶紀錄時，用來延伸斷層線；未輸入時，斷層只以不連續面符號標示。
  • 未輸入岩層代表位態時，未對比的岩層界線以水平延伸，且不繪製地層視傾角線。

步驟 7　輸出資料夾

每條剖面輸出一個 <前綴><剖面名稱><後綴>.qgz；所有剖面的圖層都存入同一資料夾的 GroProfile.gpkg。專案以相對路徑參照 GeoPackage，整個資料夾可搬移或複製給他人。

步驟 8　開始繪製地質剖面

  1. 先檢查所有設定，若有錯誤會列出需重新設定的項目並停止。
  2. 若輸出的 QGZ 或 GroProfile.gpkg 已存在，詢問是否覆蓋（GroProfile.gpkg 只取代同名剖面的圖層）。
  3. 依「地質剖面A_宜蘭」範本產出專案：圖層、樣式、版面配置（含圖例、比例尺、格線、剖面端點、孔號、地層名稱）。
  4. 完成後可在結果清單中雙擊開啟專案，或按「開啟輸出資料夾」。

地形剖面的繪製邏輯

依地質作業的截切律（較年輕的構造截切較老的構造），線段依下列順序產生，後畫的線遇到先畫的線即終止：

  1. 地形線：由 DEM 或等高線沿剖面線取樣。
  2. 鑽孔柱狀圖：投影到剖面線上。
  3. 土岩界面（覆蓋層底部的侵蝕面）：鑽孔間線性連接，兩端依最近鑽孔的覆蓋層厚度平行地形延伸。
  4. 斷層：由 MDB 斷層／斷層帶點，依斷層代表位態的視傾角向上下延伸，止於土岩界面、地表或剖面邊界。
  5. 岩層界線：相鄰鑽孔有相同上下岩層的界面時，直接連線對比（若中間有斷層則不跨斷層連線）； 未能對比的界面及最外側鑽孔，由界面在鑽孔中心的位置依岩層視傾角向外延伸， 遇到斷層、土岩界面、地表、剖面邊界，或鄰孔有鑽到該深度卻沒有此界面時即終止。
  6. 地層視傾角線：由不連續面中的層理、劈理、葉理、片理、紋層位置，依視傾角向兩側延伸，終止條件同岩層界線。
  7. 其他不連續面（節理、剪力面、裂隙、張裂隙、岩脈）：岩心未定向，只以實測角度畫短線示意，不延伸。
  8. 地下水位面。

「不整合面」需由區域地質判定，無法由鑽孔資料自動產生，可在專案中自行以該類別繪製。 地形剖面圖層的「終止」欄位記錄每條線兩端是遇到哪一種界線而終止，方便檢核。

顯示岩心照片

  • 開啟產出的剖面專案，按工具列「顯示岩心照片」，再點選地層（鑽孔柱狀圖）圖徵，右側「岩心照片」視窗即顯示該層深度範圍內的岩心箱照片； 點擊照片可以系統看圖程式開啟原圖，拉桿可縮放。
  • 也可在地層圖徵上按右鍵 →「動作」→「顯示岩心照片」，或開啟地圖提示 (Map Tips) 直接預覽。
  • 照片路徑同時存為絕對路徑及相對 GroProfile.gpkg 的路徑；搬移資料夾時請保持兩者相對位置。
  • 產製時若沒有岩心箱照片資料夾，此功能會提示「岩心照片功能停用」。

MDB 讀取說明

套件內建純 Python 的 Access (Jet 4) 讀取器，Windows、macOS、Linux 都不需另外安裝驅動程式。 若內建讀取器失敗，會改用 GDAL ODBC（需 Microsoft Access Database Engine）或 mdbtools。使用的資料表：

dr_coord、measured_attribu、case_holes、drill_attributes、geol_graphic_log、geol_rock_soil_d、 geol_weather_deg、geol_rqds、geol_rock_discon、std_proct_compac、water_tables、drill_image、kind

常見問題

  • 剖面沒有鑽孔：加大距離門檻，或檢查鑽孔座標系統與剖面線圖層座標系統是否正確（地圖上鑽孔點應落在剖面線附近）。
  • 柱狀圖高出地形：選用 MDB 井口高程時可能發生，請核對 MDB 高程或改用數值地形。
  • 無法覆蓋檔案：請先關閉正在使用 GroProfile.gpkg 的專案（開新專案）後再執行。
  • 地層圖例顯示「未定義圖元」：MDB 中的地層代碼不在規範附錄B中，請檢查 geol_graphic_log 的 code 欄位。
